# 🌐 Website Layout Clone

A modern and responsive tech startup landing page built using HTML5 and CSS3. This project recreates a professional homepage while demonstrating CSS Grid, Flexbox and responsive web design.

## ✨ Features

- Modern and attractive homepage design.
- Responsive navigation bar.
- Hero section with call-to-action buttons.
- Features section with interactive cards.
- About and services sections.
- Contact section and footer.
- CSS hover effects and smooth transitions.
- Responsive layouts for desktop, tablet and mobile.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
